## 背景
英港新三地的申请流程差别很大（有条件录取、留位费、CAS、学生准证……），原来首页是一套通用流程，地区只在项目库里筛选。改成**先选地区，点进去就是该地区自己的界面**。

## 已完成
- [x] **首页**：三张地区大卡片，地标实拍照 + 国旗 + 地区标签 + 已核实项目数，点击进入 `/uk`、`/hk`、`/sg`
- [x] **地区页**（`frontend/src/app/[region]/`）：
  - 顶部横幅：地标照片、地区名、「浏览该地区项目」「手动添加项目」
  - 「申 X 要特别注意」：该地区 4 条关键提醒
  - 该地区自己的五段申请流程，以及看板里对应的申请节点
  - 「我的 X 申请」：只列这个地区的申请
- [x] **看板**：顶部加地区标签（全部 / 英国 / 香港 / 新加坡，带数量），**默认显示全部**（联申用户多），选择写进网址
- [x] **手动添加**：从地区页进来时默认选中该地区（`?region=`）
- [x] 不存在的地区（如 `/us`）返回 404

## 地区内容放在哪
`frontend/src/lib/regions.ts` 的 `REGION_GUIDES`：图片、标语、注意事项、五段流程。**改文案只改这里**。文案只写已核实或官网普遍通用的规则，具体项目要求以项目卡片上的官网链接为准。
