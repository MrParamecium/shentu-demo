## 背景
T-005 手动添加要用户自己填学校、项目名、截止日期。更省事的做法：用户贴官网链接，系统自动识别出这些信息，**填进同一个表单**让用户核对后保存。识别失败就退回手动填，体验不会比现在差。

## 要做什么
- [ ] 手动添加页顶部加「贴官网链接，自动识别」输入框
- [ ] 后端（Render / FastAPI）接口：抓页面 → 用 AI 提取学校、项目名、各轮截止日期、语言要求 → 返回草稿
- [ ] 前端把草稿填进现有表单，**用户确认后才保存**；识别不出的字段留空
- [ ] 防刷：限频、限制页面大小、只允许 http(s)、拒绝内网地址（防 SSRF：别人借我们服务器去访问内网）
- [ ] 匿名记录「用户贴了哪些链接、最后保存的是什么」，用来决定项目库下一批收录谁

## 已知的坑（核实数据时踩过）
- UCL、新国立、南洋商学院会拦截程序抓取；港大页面是 JS 渲染，后端直接请求拿不到正文
- 页面上常同时有 2026 和 2027 年日期、全日制和非全日制两栏、奖学金截止和申请截止，AI 容易认错
- 所以**只能是草稿**，界面上要明确提示「请对照官网核对」
