# T-002 买域名并配置发信 / 前端域名

- **负责人**：浩翔
- **状态**：⬜ 待开始
- **分支**：不涉及代码，只改线上配置
- **布置人 / 日期**：浩翔 / 2026-10-23

## 背景
- 没有自有域名，Resend 只能发信给账号本人，登录无法给别人用（见 T-001）
- `*.vercel.app` 在国内可能打不开，**尚未验证**

## 要做什么
- [ ] 两人商量定域名并购买
- [ ] Resend → Domains 添加域名，按提示在域名后台加 DNS 记录，等验证通过
- [ ] Vercel 绑定前端域名（如 `www.域名`）
- [ ] Render 环境变量：`MAIL_FROM`、`CORS_ORIGINS` 加上新前端域名、`AUTH_DEMO_MODE=false`
- [ ] 找一个在国内、不开 VPN 的同学，试新域名能不能打开

## 完成标准
- [ ] 用 QQ、163、Gmail 各登录一次，都能收到验证码，记录是进收件箱还是垃圾箱
- [ ] 新前端域名在国内不开 VPN 能打开
