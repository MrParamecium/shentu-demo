# T-005 用户自己添加库里没有的项目

- **负责人**：浩翔
- **状态**：✅ 完成（已上线）
- **分支**：`t-005-custom-program`
- **布置人 / 日期**：浩翔 / 2026-10-23

## 背景
项目库再怎么扩也不可能全覆盖（港中文一所就有约 124 个授课型硕士）。用户找不到自己的项目就只能回去用 Excel，所以要允许手动添加。

## 已完成
- [x] 项目库：搜不到时显示「项目库里还没有这个项目 · 手动添加」；列表上方常驻「找不到你的项目？手动添加 →」；搜索词会带过去预填项目名
- [x] 新页面 `/programs/custom`：地区、学校、项目名、截止日期（可加到 6 轮，或勾「滚动录取」）、官网链接（选填）
- [x] 校验：学校和项目名必填；每轮要有名称和日期、日期不能重复；链接只接受 http(s)（防止存进 `javascript:` 这类地址）
- [x] 各轮按日期自动排序；没改过的默认名「第N轮」排序后重新编号，用户自己起的名字（如「补录」）保留
- [x] 数据：项目信息跟着这条申请一起存在浏览器本地（`Application.customProgram`），不进项目库
- [x] 看板、详情页和库里的项目一样能用：材料清单、按地区的节点（港留位费、英 CAS、新学生准证）、倒计时、滚动录取
- [x] 卡片标「自行添加，未核实」；外链加 `rel="nofollow"`

## 完成标准
- [x] 手动添加 → 出现在看板 → 能推进节点 → 刷新后还在
- [x] `npm run build`、`npm run lint` 通过

## 没做（以后再说）
- 已添加的自定义项目还不能编辑，填错了只能删掉重加
- 贴链接自动识别：见 [T-009](T-009-link-import.md)
- 数据同步到账号时，`customProgram` 要一起同步
