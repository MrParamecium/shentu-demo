# T-005 用户自己添加库里没有的项目

- **负责人**：待定

## 背景
项目库再怎么扩也不可能全覆盖。用户找不到自己的项目就会流失，所以要允许手动添加。

## 要做什么
- [ ] 项目库搜不到时，显示「找不到？手动添加」入口
- [ ] 表单：地区、学校、项目名、各轮截止日期（可加多轮）、官网链接（选填）
- [ ] 手动添加的项目存在浏览器本地（和现在的申请数据一样），标「自行添加，未核实」
- [ ] 看板、详情页正常显示和排序

## 完成标准
- [ ] 手动添加一个项目 → 出现在看板 → 能推进节点 → 刷新后还在
- [ ] `npm run build`、`npm run lint` 通过

## 参考资料
- `frontend/src/lib/store.ts`（本地存储写法）、`lib/types.ts`
- 以后做数据同步时，这些自定义项目也要一起同步，设计数据结构时留意
